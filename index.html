01 / MACHINE LEARNING2026

Learning from
the whole slide.

T-CAIREM Health Datathon · Breast cancer imaging

Exploring whether pretreatment biopsy images can predict complete response to neoadjuvant chemotherapy, using attention-based multiple instance learning.

Inside the project

My focus: the image-based MIL pipeline. Patch features form a patient-level bag, and an attention network learns how to combine them into a response prediction.

Patient-level five-fold cross-validation and out-of-fold predictions support evaluation. Complete response is the dataset label; its equivalence to pathological complete response requires confirmation.

03 / SYSTEMS & TRADING2026

Electronic Trading Exchange Simulator

A multi-process limit order book exchange built in C for CSC209, connecting systems programming with market mechanics.

Inside the project

Implemented an exchange matching engine with price–time priority, order insertion and cancellation, partial fills, execution reports, and position tracking.

Coordinated concurrent trader processes using Unix pipes and an event-driven I/O loop with poll(). The project applied process management, interprocess communication, synchronization, and memory management.

CUnixIPCOrder matching
04 / TIME SERIESCOURSE PROJECT

Canada’s electricity mix

Studying the dynamics of Canadian electricity generation from 2010–2023 through multivariate time-series analysis.

Inside the project

Used a vector autoregression, impulse response analysis, Johansen cointegration testing, and Granger causality tests to investigate relationships between generation sources.

Presented the modeling choices, statistical evidence, and limitations in a team presentation for STAD57.

VARCointegrationStatistical modeling
